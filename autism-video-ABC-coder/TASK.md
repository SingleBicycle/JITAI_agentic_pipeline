Reference video-labeler, and create autism-video-coder

autism-video-coder allows user to mount a folder of videos, the app reads/loads 1 video at a time

allows user to label video clips and segments. for each event clip, take start and end to label the clip.

during each event clip, allow users to tag segments/chunks from this clip with tags: antecedent, behavior, and consequence.

once user pressed any of those tags, the data recorder starts treat that timestamp onward as labeled with that tag, until the user click another tag, clip end, or click clear/no tag etc.

for visualizations, for the progress bar, label it with the corresponding start / end for each event and the tag duration occupying that time window
